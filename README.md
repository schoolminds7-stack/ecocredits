# EcoCredits

Turn recyclable waste into everyday value.

## Stack

- React 19
- Vite 6
- Tailwind CSS v4
- TanStack Router
- Zustand (local persistence)

## Run

```bash
npm install
npm run dev
```

Open http://localhost:8080
